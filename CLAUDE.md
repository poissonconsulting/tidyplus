## Package Overview

tidyplus is a CRAN R package providing additional tidyverse functions that either complement tidyverse functionality (`str_crush()`, `add_missing_column()`, `coalesce_data()`, `drop_na_all()`) or offer alternative behaviors (`if_else2()`, `str_detect2()`).

## Commands

Run from the package root via `Rscript -e '...'` or an R session:

- Test all: `devtools::test()`
- Test one file: `devtools::test(filter = "coalesce-data")` (matches `tests/testthat/test-coalesce-data.R`)
- Document (roxygen2): `devtools::document()`
- Full check: `devtools::check()`
- Format: `air format .` (config in `air.toml`, 80-char lines, 2-space indent)
- Lint: see `scripts/build.R` for the configured lintr call (line length and object name linters relaxed)

`scripts/build.R` is the full release pipeline (roxygen2md, lint, test, document, pkgdown, check).

## Structure and Conventions

- One exported function per file in `R/`, with a matching `tests/testthat/test-<name>.R` file. File names use hyphens (`str-crush.R`); function names use snake_case (`str_crush()`).
- Every exported function validates all arguments with `chk_*` calls at the top of the function body. chk is imported wholesale (`@import chk` in `R/tidyplus-package.R`) so chk functions are used unqualified; all other dependencies use `pkg::fun()` or `@importFrom`.
- Shared internal helpers live in `R/utils-internal.R`; test-only helpers (e.g., `expect_snapshot_data()`, which snapshots a data frame as CSV and is skipped on CI and Windows) live in `R/test-helpers.R`.
- Data-frame functions preserve sf objects: check with `vld_s3_class(x, "sf")`, convert to tibble, operate, then restore with `sf::st_as_sf()` (sf is Suggests, guarded by `rlang::check_installed()`). Follow this pattern in new data-frame functions.
- testthat edition 3 with snapshot tests in `tests/testthat/_snaps/`.
